# 题库 Markdown 格式规范

## 概述

本系统使用 Markdown (.md) 文件作为题库的存储格式。每个文件代表一个题库，包含若干题目。

## 文件结构

```markdown
# 题库标题

## Q1 [题型]
题目内容

选项（选择题需要）

**答案：** 正确答案

**解析：**
解析内容

---

## Q2 [题型]
...
```

## 支持的题型

| 题型标签 | 说明 | 答案格式 |
|---------|------|---------|
| `[单选]` | 单项选择题 | 单个字母，如 `A` |
| `[多选]` | 多项选择题 | 多个字母连写，如 `ABC` |
| `[判断]` | 判断题 | `A`（正确）或 `B`（错误） |
| `[填空]` | 填空题 | 文本内容 |
| `[代码选择]` | 含代码的选择题 | 单个字母，如 `A` |
| `[代码填空]` | 含代码的填空题（用户输入代码答案） | 文本/代码内容 |
| `[编程]` | 编程题（根据要求编写代码） | 参考代码，自我对照 |

## 详细格式说明

### 1. 题库标题（必须）

文件第一行使用一级标题：

```markdown
# Java 基础题库
```

### 2. 题目编号和类型（必须）

使用二级标题，格式为 `## Q编号 [类型]`：

```markdown
## Q1 [单选]
## Q2 [多选]
## Q10 [代码选择]
```

### 3. 题目内容（必须）

紧跟标题后的文本为题目内容，支持以下 Markdown 格式：

- **粗体**：`**文字**`
- *斜体*：`*文字*`
- 行内代码：`` `代码` ``
- 代码块：使用三个反引号包裹
- 表格：使用 `|` 分隔列，`---` 分隔表头

````markdown
请阅读以下代码：

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}
```
````

### 4. 选项（选择题/判断题/代码题必须）

每个选项占一行，格式为 `字母. 选项内容`：

```markdown
A. 选项 A 的内容
B. 选项 B 的内容
C. 选项 C 的内容
D. 选项 D 的内容
```

> 注意：字母和点之间不能有空格，点后面需要一个空格。

### 5. 答案（必须）

使用 `**答案：**` 标记，后面跟正确答案：

```markdown
**答案：** A          ← 单选题
**答案：** ABC        ← 多选题
**答案：** A          ← 判断题（A=正确，B=错误）
**答案：** break      ← 填空题（单空单答案）
```

### 填空题答案规则

填空题答案的写法取决于题目中 `___` 的数量：

**规则一：单空单答案**（题目只有 1 个 `___`）
```markdown
**答案：** break
```

**规则二：单空多答案**（题目只有 1 个 `___`，多个答案都对）—— 用 `|` 分隔
```markdown
**答案：** final | static final
```

**规则三：多空按序**（题目有多个 `___`，答案按空位顺序）—— 用 `|` 分隔，答案数 = `___` 数
```markdown
题目：___、___、___
**答案：** 封装 | 继承 | 多态
```

**规则四：多空乱序**（不限制填写顺序）—— 用 `||` 分隔
```markdown
**答案：** 封装 || 继承 || 多态
```

**附加：每空备选答案** —— 用 `/` 分隔同一空位的可接受写法
```markdown
**答案：** 封装/encapsulation || 继承/inheritance || 多态/polymorphism
```

> **关于空位标记**：`___`（3个下划线）和 `____`（4个下划线）均可作为空位标记使用，代码题中常用 `____` 表示占位空。系统会自动将任意 3+ 个连续下划线视为一个空位。

### 编程题答案规则

编程题 `[编程]` 用于让用户根据题目要求编写完整代码。答案为参考解答（代码块），供用户写完后自行对照。

**作答方式**：用户在大代码编辑框中编写代码，即时模式下点击"提交查看参考解答"后对照参考答案，自行判断对错。考试模式下统一提交后在结果页对照。

**答案格式**：直接写参考代码（无需字母选项），支持多行代码块：

````markdown
## Q1 [编程]
编写一个方法，计算两个整数的最大公约数。

**答案：**
```java
public static int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}
```

**解析：**
使用欧几里得算法（辗转相除法）...
````

> **注意**：编程题为**自评题型**，用户对照参考解答自行判断是否正确。答案匹配时不区分大小写和首尾空格。

### 6. 解析（必须）

使用 `**解析：**` 标记，后面跟解析内容：

```markdown
**解析：**
这是一段解析内容，支持 **Markdown** 格式。

还可以包含代码块：

```java
int x = 10;
```
```

### 7. 题目分隔（推荐）

题目之间使用 `---` 分隔：

```markdown
**解析：**
解析内容...

---

## Q2 [多选]
...
```

## 完整示例

````markdown
# Java 基础题库

## Q1 [单选]
Java 中哪个关键字用于实现接口？

A. extends
B. implements
C. interface
D. abstract

**答案：** B

**解析：**
`implements` 关键字用于类实现接口。`extends` 用于继承，`interface` 用于声明接口，`abstract` 用于声明抽象类或方法。

---

## Q2 [代码]
阅读以下代码：

```java
public class Test {
    public static void main(String[] args) {
        int x = 10;
        int y = 20;
        System.out.println(x + y);
    }
}
```

程序的输出结果是？

A. 1020
B. 30
C. x + y
D. 编译错误

**答案：** B

**解析：**
`x + y` 执行的是整数加法运算，10 + 20 = 30。
````

### 编程题示例

````markdown
## Q3 [编程]
编写一个 Java 方法，接收一个整数 n，返回 n 的阶乘。

**答案：**
```java
public static int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```

**解析：**
使用递归实现，边界条件 `n <= 1` 返回 1，否则返回 `n * factorial(n - 1)`。
````

## 导入导出

- **导入**：在首页点击"导入题库"按钮，选择 `.md` 文件即可
- **导出**：在首页点击"导出题库"按钮，将当前题库保存为 `.md` 文件
- 导入和导出完全兼容，导出的文件可以再次导入

## 英文标签兼容

本系统同时支持英文题型标签，以下两种写法等价：

| 中文标签 | 英文标签 |
|---------|---------|
| `[单选]` | `[single]` |
| `[多选]` | `[multi]` |
| `[判断]` | `[truefalse]` |
| `[填空]` | `[fill]` |
| `[代码选择]` | `[code]` 或 `[codechoice]` |
| `[代码填空]` | `[codefill]` |
| `[编程]` | `[programming]` |

答案和解析也支持英文标记：

```markdown
**Answer:** B
**Explanation:**
This is the explanation.
```

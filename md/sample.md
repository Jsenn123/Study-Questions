## Q1 [单选]
JavaScript 中 `typeof null` 的返回值是？

A. `"null"`
B. `"object"`
C. `"undefined"`
D. 抛出 TypeError

**答案：** B

**解析：**
这是 JavaScript 著名的历史遗留问题：`null` 的类型标签与对象同为 `000`，因此 `typeof null` 返回 `"object"`。判断某个值是否为 `null`，应当使用 `=== null`，而不是 `typeof`。

## Q2 [多选]
关于 HTTP 状态码，下列说法正确的有？

A. 200 表示请求成功
B. 301 表示临时重定向
C. 404 表示请求的资源不存在
D. 500 表示服务器内部错误

**答案：** ACD

**解析：**
301 是**永久**重定向，临时重定向对应的是 302 与 307。常见状态码归类如下：

| 状态码 | 含义 | 分类 |
|--------|------|------|
| 200 | 请求成功 | 成功 |
| 301 | 永久重定向 | 重定向 |
| 302 | 临时重定向 | 重定向 |
| 404 | 资源不存在 | 客户端错误 |
| 500 | 服务器内部错误 | 服务端错误 |

- 4xx 系列表示请求方的问题
- 5xx 系列表示服务端的问题

## Q3 [判断]
Python 中的元组（tuple）是不可变类型。

**答案：** A

**解析：**
元组一旦创建，就不能增删改其中的元素；但如果元组内部含有可变对象（例如列表），该对象自身仍然可以被修改。需要可变序列时应当使用列表 `list`。

## Q4 [填空]
在 Python 中，创建一个空字典可以写作 ___（写出任意一种写法即可）。

**答案：** {} | dict()

**解析：**
`{}` 与 `dict()` 完全等价，都得到空字典。注意 `{}` 创建的是字典而不是集合，空集合需要写作 `set()`。

## Q5 [填空]
HTTP 请求方法中，___ 用于获取资源，___ 用于提交数据，___ 用于删除资源。

**答案：** GET | POST | DELETE

**解析：**
本题考查多空按序作答：三个空位的答案用 `|` 分隔，顺序必须与空位一一对应。补充常用的其余方法：`PUT` 表示整体更新，`PATCH` 表示局部更新，`HEAD` 只获取响应头。

## Q6 [填空]
以下三种排序算法的平均时间复杂度均为 O(n log n)：___、___、___（填写顺序不限）。

**答案：** 快速排序/quicksort || 归并排序/mergesort || 堆排序/heapsort

**解析：**
答案用 `||` 分隔表示**不限填写顺序**，每个空位内再用 `/` 分隔可接受的多种写法（本行同时演示了中英文写法均可接受）。

| 算法 | 平均时间复杂度 | 最坏时间复杂度 | 稳定性 |
|------|----------------|----------------|--------|
| 快速排序 | O(n log n) | O(n²) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | 稳定 |
| 堆排序 | O(n log n) | O(n log n) | 不稳定 |

## Q7 [代码选择]
阅读以下 Java 代码，程序的输出结果是？

```java
public class Main {
    public static void main(String[] args) {
        int x = 10;
        int y = 20;
        System.out.println("" + x + y);
    }
}
```

A. 30
B. 1020
C. x + y
D. 编译错误

**答案：** B

**解析：**
`"" + x + y` 中最先出现的是字符串拼接：表达式从左向右求值，`""` 使整个表达式按字符串处理，后续的 `+` 都变成连接运算，最终得到 `"1020"`。若改写为 `x + y + ""`，则会先完成整数加法，结果为 `"30"`。

## Q8 [代码填空]
补全下面的 Python 代码，使其能把文件内容一次性读入变量 `content`。

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = ____
```

**答案：** f.read()

**解析：**
`f.read()` 会一次性读取全部内容并返回一个字符串；`f.readlines()` 返回按行切分的列表；`f.readline()` 则只读取一行。本题要求“一次性读入”，因此应使用 `f.read()`。

## Q9 [编程]
编写一个函数，判断给定字符串是否为回文（正读与反读相同），比较时忽略大小写与非字母数字字符。

**答案：**
```python
def is_palindrome(s):
    cleaned = [ch.lower() for ch in s if ch.isalnum()]
    return cleaned == cleaned[::-1]
```

**解析：**
先过滤出字母与数字字符并统一转为小写，再把清洗后的序列与其逆序比较。`cleaned[::-1]` 是 Python 中反转序列的常用写法，不会修改原列表。本题为自评题型：写完后与上面的参考解答对照，判断自己的实现是否正确即可。

# 📝 在线刷题

一个纯前端刷题工具，用 Markdown 管理题库，支持多种题型和两种刷题模式。

## ✨ 功能

- **两种刷题模式**：即时模式（每题即时反馈） / 考试模式（全部提交后统一查看）
- **七种题型**：单选、多选、判断、填空、代码选择、代码填空、编程
- **代码编程题**：大代码编辑区，支持对照参考解答
- **Markdown 题库**：导入导出 `.md` 文件，人机皆可读写
- **多空填空题**：支持多空、乱序、备选答案
- **22 种语言代码高亮**：Java、Python、C/C++、Go、Rust、SQL 等
- **暗色主题**：亮色/暗色一键切换
- **题型筛选**：按题型过滤题目导航
- **数据本地存储**：题库保存在浏览器 localStorage 中
- **完全离线**：所有资源本地化，无需网络

## 🚀 快速开始

直接用浏览器打开 `index.html` 即可使用；也可以用 Electron 桌面应用方式运行：

```bash
npm install
npm start
```

1. 点击「📥 导入题库」选择 `md/sample.md` 先试一下（或选择你自己的 `.md` 题库文件，格式见 [md/FORMAT.md](md/FORMAT.md)）
2. 选择刷题模式（即时 / 考试）
3. 开始刷题

## 📁 目录结构

```
题库/
├── index.html          # 入口页面
├── css/
│   └── style.css       # 样式（亮暗主题）
├── JS/
│   └── app.js          # 核心逻辑（解析器+渲染+存储）
├── lib/
│   └── highlightjs/    # 代码高亮（22种语言）
├── md/
│   ├── FORMAT.md       # 题库格式规范
│   └── sample.md       # 示例题库（覆盖全部 7 种题型）
├── main.js             # Electron 主进程入口
├── preload.js          # 预加载脚本（当前为空）
├── package.json        # 依赖与启动脚本
└── README.md           # 自述文件
```

> 题面 Markdown 由 `JS/app.js` 自带的轻量 `renderMd` 渲染，不依赖第三方 Markdown 库。

## 📋 支持的题型

| 题型 | 标签 | 说明 |
|------|------|------|
| 单选题 | `[单选]` | 四选一 |
| 多选题 | `[多选]` | 多选，即时模式需点确认 |
| 判断题 | `[判断]` | 正确/错误 |
| 填空题 | `[填空]` | 支持多空（`___`）、乱序（`\|\|`）、备选答案（`/`） |
| 代码选择题 | `[代码选择]` | 含代码片段的单选题 |
| 代码填空题 | `[代码填空]` | 代码中留空（`____`），用户填写 |
| 编程题 | `[编程]` | 编写完整代码，对照参考解答 |

## 📝 题库 Markdown 格式

```markdown
# 题库名称

## Q1 [单选]
题目内容（支持 **Markdown** 和 `代码`）

A. 选项A
B. 选项B
C. 选项C
D. 选项D

**答案：** B

**解析：**
解析内容...

---
```

详细格式规范见 [md/FORMAT.md](md/FORMAT.md)。

## 💡 使用技巧

| 场景 | 推荐模式 |
|------|---------|
| 日常练习/学习 | 即时模式 |
| 模拟考试/自测 | 考试模式 |
| 面试准备 | 即时模式 + 编程题 |
| 课堂测验 | 考试模式 |

- 题库保存在浏览器中，清除缓存前不会丢失
- 导出题库可备份到本地 `.md` 文件
- `Ctrl+Shift+R` 强制刷新可加载最新代码
